DC/DC, 접촉기, 분배 단자, 퓨즈 하우징, 비상정지 박스, RESET, USB 허브, 레벨 인터페이스, 보강대, 제어 커버는 추가 설계품 또는 공간예약이다. 외형이 보인다는 이유로 특정 판매제품과 일치한다고 해석하면 안 된다.

V8에서 별도 제품사진이나 정확한 도면이 제공되지 않은 부품의 IC·방열판·팬·단자 디테일은 시각 참고 형상이다. PCB 배선 패턴이나 케이스 내부까지 실물을 복제한 것은 아니다. 원본 18kg 시나리오는 이번 카트의 검증된 총중량·적재하중이 아니며 승차를 허용하지 않는다.
