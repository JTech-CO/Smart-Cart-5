## 2. Smart-Cart-4에서 바꾼 범위

원본: https://github.com/JTech-CO/Smart-Cart-4  
확인한 기본 브랜치 스냅샷: `0d91785fc66699fb12a4c7b55bae2dfbb1adad1c`

원본의 전체 알루미늄 프로파일 구조와 이전 전장 배치를 그대로 축소하지 않았다. V8에 맞춰 기성 플랫폼·보강대·높이 연결대·배터리 트레이로 구조를 새로 구성했다. V8에 없는 전륜 서보/ToF 등의 이전 부품을 자동으로 이월하지 않았다. 앞바퀴는 자유회전 캐스터, 뒤는 좌우 독립 구동이다. 이전 제어 펌웨어나 자율추종 알고리즘을 이 패키지에 이식한 것은 아니다.

렌더러는 새 D5 메시와 Z-up 좌표를 사용한다. 시점이 아래로 내려갈 때 지면을 그리지 않으며, 상판·커버·배선을 독립 제어한다. CPU 호환 경로도 동일한 메시를 사용한다. CAD에는 D4의 숨겨진 과거 형상을 넣지 않는다.

## 3. Motor-Bracket 통합

원본: https://github.com/JTech-CO/Motor-Bracket

- `parameters.json` blob SHA: `81c48461c54e75b0c63525a2e6f43806858f77a3`
- `src/build_cadquery.py` blob SHA: `7b62a49bb4a3ead57460ee48a6d83fc5e8503644`
- `README-KR.md` 및 FCStd 패키징 소스의 구조·한계 설명도 확인했다.

`tools/bracket_geometry.py`는 원본의 솔리드 생성 구조를 재현한다. 외곽, 8mm 주요 판, R10 루트, 큰 경량화 창, Ø60 축 주변 여유, 비대칭 모터 홀과 차체 체결홀을 유지했다. 재생성한 본체 한 개의 질량은 밀도 2.7e-6kg/mm³에서 약0.615083kg이다. 이는 단순 외곽 블록으로 대체한 브라켓이 아니라 실제 관통홀과 창을 가진 BREP 솔리드이다.

반대편에는 동일한 가공품을 Z축으로 180° 회전했다. 홀을 반전한 별도 거울상 부품은 아니다. 원본의 8mm 스페이서와 88mm 축-접촉상면 높이를 보존하고, 카트와 연결하는 높이 보정대는 별도 D/M 부품으로 추가했다.

**자료 충돌:** Motor-Bracket의 모터 참고 외곽은 Ø102, V8 본문은 Ø72이다. 이 모델은 사용자가 이번 작업의 기준으로 지정한 V8의 Ø72를 사용한다. Ø102를 실측값으로 채택하거나, Ø102 대체 외곽까지 간섭 검증했다고 주장하지 않는다. 입고 모터 실측 후 해당 형상과 경로를 다시 검사해야 한다.

원본의 18kg 하중 시나리오, 모터축 허용하중 미확정, 제작 승인 보류는 해소되지 않았다. 배터리 2개만 명목 약11kg이므로 18kg을 이번 카트의 검증된 운행 총중량으로 표시하지 않는다.

## 4. V8에 없는 추가품

24V 계통용 접촉기 K1, 정비용 분리 커넥터, 퓨즈 홀더·퓨즈, 5.1V DC/DC, 분배 단자, 수동 RESET, 외부전원 USB 허브, 제어 인터페이스, 절연 부싱과 보강 부품을 추가 설계했다. 이들은 회로 구성과 물리적 설치 공간을 표시하기 위한 **설계 제안/공간예약**이다. 특정 구매품의 재고, 가격, 외형, 정격과 일치함을 확인한 것은 아니다.

손잡이 비상정지는 사용자 요구에 따른 추가 구성이다. 2개의 납축전지 직렬 전원, 구동/보조 전원 분기와 코일 자기유지 회로를 분리해 표현한다. 단, 이 모델은 안전 등급을 인증한 회로나 개별 PCB 핀까지 확정한 제작 배선도가 아니다. [통전 보류 조건](ELECTRICAL-HOLD-KR.md)을 함께 읽는다.

## 5. 재질과 시각 디테일

금속·고무·도장·배터리 수지·PCB·전선 피복의 색, 금속성, 거칠기, 표면 패턴과 부품 라벨을 사용한다. V8의 미확인 제품사진을 대신 실제 제품사진을 확보했다고 주장하지 않는다. IC 배치·팬 블레이드·케이스 방열부·타이어 트레드 등은 식별과 공간 검토를 위한 시각 참고이다. 실물 제품의 모든 내부 구조를 복제한 것은 아니다.

`docs/source-provenance.json`은 제공 DOCX와 로컬 기준 JSON의 SHA-256을 기록한다. `SHA256SUMS.txt`는 배포 파일 무결성 목록이며 실제 제품의 치수 인증이나 제작 승인을 뜻하지 않는다.
